# CARRY1 site

Static site for CARRY1 (fractional revenue leadership from Sarah Miner, Founder). Live at https://gelbius.github.io/sarah-miner/

This repo holds the built output only (plain HTML + one CSS file, served by GitHub Pages from `main` at the root). Essays are Sarah's long-form LinkedIn posts; each links back to the original.

Brand: navy `#142F5A`, gradient `#FFCE99` to `#BD7D3D` (accents only; copper only for large text or decoration), Montserrat (self-hosted WOFF2 subsets in `assets/fonts`, OFL). Logo, favicons and fonts come from the CARRY1 brand kit.

Placeholders for future client metrics are HTML comments marked `CLIENT METRIC SLOT`, `CLIENT SLOT` and `CASE STUDY SLOT` (index.html, work.html). Only publish numbers Sarah has approved.
